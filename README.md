# Статическая версия сервиса «Земельный налог по кадастровой оценке»

Поиск участка по кадастровому номеру и расчёт налога выполняются в
браузере. Сервер и СУБД не нужны: сайт состоит из одной страницы
`index.html` и каталога `data/` с данными ГКО Саратовской области
(тур 2019 и тур 2022, 908 595 участков, 22,8 МБ).

Ноль вместо стоимости означает, что в этом туре участка нет. Группа
ставки: 0 — жилой фонд, 1 — ЛПХ и садоводство, 2 — сельхозиспользование,
3 — оборона, 4 — прочие, 5 — не определена. `data/rates.json` —
справочник ставок, собранный из `data_templates/rates_saratov.csv`
основного проекта.

## Проверка расчёта

`tools/ref.py` считает налог модулем `valuation/taxes.py` основного
проекта для случайной выборки участков, `tools/check.mjs` повторяет
расчёт модулем из `index.html` и сравнивает. Результат на момент
сборки: 6 137 участков, 62 268 сверок, расхождений нет.

## Отличия от основной версии

- Нет подсистемы администрирования и журнала импорта: данные
  готовятся заранее скриптом.
- Вычет 600 кв.м применяется и к новому туру, если площадь известна
  по выгрузке 2019 года (в выгрузке 2022 года площади нет). Если
  площади нет вовсе, её можно ввести вручную.
- Можно вписать свою ставку, а долю, срок владения и вычет задать
  прямо на странице.
- Если группа ставки по сведениям 2019 года не совпадает с оценочным
  сегментом 2022 года, страница предупреждает об этом.
