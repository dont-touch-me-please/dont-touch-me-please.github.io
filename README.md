# Статическая версия сервиса «Земельный налог по кадастровой оценке»

Поиск участка по кадастровому номеру и расчёт налога выполняются в
браузере. Сервер и СУБД не нужны: сайт состоит из одной страницы
`index.html` и каталога `data/` с данными ГКО Саратовской области
(тур 2019 и тур 2022, 908 595 участков, 22,8 МБ).

## Размещение на GitHub Pages

1. Зарегистрируйтесь на github.com и создайте новый **публичный**
   репозиторий, например `gko-nalog`.
2. На странице репозитория: **Add file → Upload files**. Перетащите
   в окно содержимое этой папки: `index.html`, `.nojekyll` и папку
   `data` целиком. За один раз GitHub принимает до 100 файлов —
   здесь их 58, хватит одной загрузки. Нажмите **Commit changes**.
3. **Settings → Pages → Build and deployment**: Source — «Deploy from
   a branch», Branch — `main`, папка `/ (root)`. Нажмите **Save**.
4. Через одну-две минуты сайт откроется по адресу
   `https://ВАШ_ЛОГИН.github.io/gko-nalog/`.

Ссылку на конкретный участок можно дать так:
`https://ВАШ_ЛОГИН.github.io/gko-nalog/?n=64:32:024013:790`.

Каталог `tools/` для работы сайта не нужен, загружать его не обязательно.

## Проверить на своём компьютере

Двойной щелчок по `index.html` не сработает: браузер не даёт странице,
открытой как файл, читать соседние файлы. Запустите в этой папке

    python -m http.server 8000

и откройте http://127.0.0.1:8000/.

## Устройство данных

Один файл на кадастровый район: `data/32.json` — район 64:32. Внутри
участки сгруппированы по кварталам, запись об участке:

    [номер, КС 2022 (коп.), КС 2019 (коп.), площадь (кв.м × 100),
     оценочный сегмент, группа ставки]

Ноль вместо стоимости означает, что в этом туре участка нет. Группа
ставки: 0 — жилой фонд, 1 — ЛПХ и садоводство, 2 — сельхозиспользование,
3 — оборона, 4 — прочие, 5 — не определена. `data/rates.json` —
справочник ставок, собранный из `data_templates/rates_saratov.csv`
основного проекта.

## Обновление данных

Данные собирает `tools/build_static.py` теми же модулями чтения, что
и основной проект, поэтому папка `gko` (основной проект) должна лежать
рядом с папкой `gko-static`:

    python build_static.py КАТАЛОГ_2019 КАТАЛОГ_2022 КАТАЛОГ_САЙТА

После изменения ставок в `rates_saratov.csv` достаточно пересобрать и
заменить на GitHub один файл `data/rates.json`.

## Проверка расчёта

`tools/ref.py` считает налог модулем `valuation/taxes.py` основного
проекта для случайной выборки участков, `tools/check.mjs` повторяет
расчёт модулем из `index.html` и сравнивает. Результат на момент
сборки: 6 137 участков, 62 268 сверок, расхождений нет.

## Отличия от основной версии

- Нет подсистемы администрирования и журнала импорта: данные
  готовятся заранее скриптом.
- Вычет 600 кв.м применяется и к новому туру, если площадь известна
  по выгрузке 2019 года (в выгрузке 2022 года площади нет). Если
  площади нет вовсе, её можно ввести вручную.
- Можно вписать свою ставку, а долю, срок владения и вычет задать
  прямо на странице.
- Если группа ставки по сведениям 2019 года не совпадает с оценочным
  сегментом 2022 года, страница предупреждает об этом.
